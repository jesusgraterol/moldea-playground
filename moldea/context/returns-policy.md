# Returns policy

Standard returns may be requested within 30 calendar days after the recorded delivery date, including the date that is 30 days after delivery. Compare the UTC currentDate supplied in support context with the recorded deliveredAt date. An undelivered order has no confirmed return window yet.

A standard return requires an unused item with its original tags. Item condition and tags are not recorded in the catalog: ask about them when the customer has not supplied that information. Final-sale items do not qualify for a standard return. Membership alone does not change these rules.

Get the order from the current account before giving purchase-specific guidance. Identify the item when an order contains multiple products with different eligibility. Do not promise eligibility when order identity, item identity, condition, tags, or delivery date remains unclear.

For an eligible standard request, explain that the representative can help arrange authorization. Do not claim that a return label, authorization, exchange, or refund has been created. Do not promise an amount, shipping charge, refund timing, or exception not established here.

Outside-window requests, damaged-item disputes, final-sale exceptions, missing delivery dates for delivered orders, and requests to actually issue a refund or authorize a return require human_review. A question about the policy itself can be answered without an order. Cite /moldea/context/returns-policy.md for these rules and verified order IDs for purchase facts.
